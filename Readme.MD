### Exercício API Petshop

- #### Esta API demonstra o funcionamento de um Petshop Simples de banho

### Tecnologias:

![Blog](https://img.shields.io/badge/Java-ED8B00?style=for-the-badge&logo=openjdk&logoColor=white) 


### Funcionalidades utilizadas:

- Coloca Pet para banho registrando nome
- Consome Água e Shampoo
- Adiciona Água e Shampoo
- Verifica e Retira Pet da Máquina


#### Para testar a API, recomendo o aplicativo postman. Executar api e abrir swagger na porta local.
